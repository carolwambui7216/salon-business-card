# 💇‍♀️ Ngacha's Salon & Beauty - Digital Business Card

A sleek, modern, and fully responsive digital business card built for a premium beauty salon. This project was developed as a hands-on challenge to master semantic layout structure, fluid spacing, and modern UI/UX color palettes.

## 🚀 Live Demo
🌐 [View the Live Project](https://github.io)

## ✨ Features
- **100% Validated Code**: Confirmed zero errors and zero warnings via the official W3C HTML5 and CSS3 Validators.
- **Aesthetic Color Palette**: Designed with soft blush pinks, deep luxury espresso typography, and interactive hover states tailored for a modern salon brand.
- **Flexbox Architecture**: Clean, structured stacked columns for contact details that scale seamlessly.
- **Mobile Responsive**: Optimizes layout tracking dynamically when shifting from desktop view to mobile phone dimensions.

## 🛠️ Built With
- **HTML5**: Structured semantically using native components for clean SEO mapping.
- **CSS3**: Crafted utilizing CSS Flexbox, custom media queries, and smooth micro-interactions.
